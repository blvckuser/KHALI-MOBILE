GENERATORE ETICHETTE - WEB iPHONE (PROTOTIPO)

1. Carica il contenuto di questa cartella in un repository GitHub.
2. Su Cloudflare Pages scegli Workers & Pages > Create > Pages > Connect to Git.
3. Seleziona il repository, build command vuoto, output directory / (root).
4. Apri il link HTTPS fornito da Cloudflare con Safari su iPhone.
5. In Safari scegli Condividi > Aggiungi alla schermata Home.

Nessun server di elaborazione: i PDF vengono elaborati nel browser.
Le librerie PDF.js e pdf-lib sono caricate da jsDelivr; la prima apertura richiede Internet.
Non è garantito il funzionamento offline delle librerie esterne.

IMPORTANTE: versione prototipo. Testare il PDF Ordine.pdf, il rendering dei codici a barre e la lettura con scanner prima dell'uso reale. Verificare ordini con più pagine e più articoli. Non sostituisce ancora il software Windows validato.
